STREAMER.BOT IMPORT
===================
Import 5HVLED-Stream-Attendance-All-In-One.sb after running the main installer.

The import assumes the app is installed by INSTALL.bat to your Windows Documents folder under:
  5HVLED-Attendance

It does NOT contain Khaled's Windows username or hardcoded personal path.
It resolves each user's Documents folder automatically.

After import, verify:
- Twitch is connected.
- OBS is connected.
- If there are multiple OBS connections, open the Streaming Started / Stopped triggers and choose the correct OBS connection.
