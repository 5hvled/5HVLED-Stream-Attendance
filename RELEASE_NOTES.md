# 5HVLED Stream Attendance v1.0.0

Initial public release.

### Included

- One-click Windows installer
- Local Flask + SQLite attendance dashboard
- Automatic OBS stream start/stop attendance sessions
- 24-hour session reopening
- Twitch First Words check-in
- Automatic absence recording
- Permanent attendance history
- Every-5-absences timeout eligibility and mods-mercy warning
- `!attendance` / `!atd` viewer stats with current streak
- 24-hour end credits for attendees, followers, subscribers and donors
- Streamlabs, Ko-fi, Fourthwall and TipeeeStream donation triggers
- OBS text-file credits output with scroll-loop spacing
- Backup and full reset utilities

See `README.md` for installation and usage.
